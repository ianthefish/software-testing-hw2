# Q3 - 在 CI 加入覆蓋率驗證

採用 coverage.py 7.17.0，固定於 requirements-dev.txt。本機 Python 3.12.14；GitHub Actions 指定 Python 3.12。工具在測試之外額外量測產品模組 calculator 的語句與分支覆蓋率。

.coveragerc 設定 branch=True、source=calculator、show_missing=True，門檻為 100%。門檻是本次對極小計算器採用的選擇，不是 PDF 規定。沒有將測試程式或執行器算入分母，也沒有使用 omit 或 pragma 排除產品程式。

## 實際結果

- 15 個語句，全數執行；Miss=0。
- 2 個分支，全數走到；BrPart=0。
- 覆蓋率 100%，門檻檢查 exit code 0。
- 六個主程式測試方法全數通過。
- Q7 的十個測試在其自己的資料夾另行執行，避免匯入主程式而測錯版本。

分支來自 divide 的 b == 0 條件，正常除法與除零測試分別涵蓋兩側。modulo 和 power 的例外來自 Python 內建運算子，coverage 不會把直譯器內部的分支計入這個模組，因此仍需要明確的例外 assertion；100% 並不代表所有內建行為或輸入都已測遍。

## 工具的用途與限制

Coverage 能指出測試沒有執行到的語句及分支；門檻可以在 CI 阻擋覆蓋率倒退。但執行過一行不等於 assertion 正確，也不保證負數、浮點、極大數、效能或安全性都正確。例如把減法改成加法仍可能達到 100% 覆蓋率，只有正確的預期結果才能抓到錯誤。Q2 的故障實驗和 Q7 的變形關係提供不同於覆蓋率的驗證角度。
