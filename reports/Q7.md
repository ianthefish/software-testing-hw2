## 是否特判測試輸入

程式使用一般的 +、-、*、/ 運算式，沒有查表、依 (2,3) 等測試輸入回傳常數，也沒有在其他輸入隨意回傳預設值。b == 0 的條件是已測試的例外契約，不是迎合特定案例的不當硬編碼。

## 後加的變形測試

| 關係 | 輸入範圍 | 數量 |
| --- | --- | --- |
| subtract(add(a,b),b) == a | a,b 各 -25 至 25 | 2,601 組 |
| subtract(a,b) == -subtract(b,a) | a,b 各 -25 至 25 | 2,601 組 |
| multiply(a,add(b,c)) == add(multiply(a,b),multiply(a,c)) | a,b,c 各 -10 至 10 | 9,261 組 |
| divide(multiply(a,b),b) 約等於 a | a,b 各 -25 至 25，排除 b=0 | 2,550 組 |
| 上述四種關係的較大輸入 | 整數 -1,000,000 至 1,000,000；種子 20261025 | 1,000 組三元組 |

使用 unittest 的 subTest 逐筆驗證，預期結果由運算關係產生，沒有新增固定輸入對固定答案的查表。乘除反向關係使用 math.isclose，rel_tol=1e-12、abs_tol=1e-12；除數為零不屬於此性質的定義域。零除數的例外仍由原 Q1 測試驗證。

新增五個 test methods 後，原五個加新五個，共 10 個全部通過，exit code 0。有限範圍的前四項合計 17,013 組關係驗證，另有 1,000 組固定種子樣本各檢查多項關係。輸出保存於 evidence/metamorphic.txt。property tests 加入提交 db453e7，位於首次實作之後。

## 結論與限制

此次未觀察到固定輸入特判，新增的變形測試也沒有揭露錯誤。因此沒有修改首次生成版本或削弱性質來取得綠燈。結果不能證明所有整數、任意大數或非整數都正確；例如極大整數轉浮點可能涉及溢位，本實驗未涵蓋。

輸入測試來自本次 Q1 重做，並非已驗證的使用者無 AI 原始測試。新 session 有程序上的輸入限制，並非作業系統權限隔離。experiments/q7/ 保存獨立專案內容，evidence/q7/git-log.txt 保存獨立提交順序。
