# Q6 - Agentic TDD：modulo 與 power

## 規格先確認

使用者在本對話明確選擇 Python 規則：非零餘數與除數同號、modulo by zero 拋 ZeroDivisionError、power(0,0) 回傳 1、負指數回傳 float、0 的負次方拋 ZeroDivisionError。

## Cycle 01：完整的整數輸入契約

先新增一個 unittest test method：test_modulo_and_power_contract，內有 17 組 subTest。六組 modulo 數值案例、八組 power 數值案例與三組例外案例，全部在任何 modulo/power 實作存在之前定義並執行。原有五個 Q1 測試仍通過；新測試因方法不存在而產生 17 個 AttributeError，整體 exit code 1。

這裡的「一個測試」按 unittest 的 test method 計數，17 組資料並非 17 輪 TDD。採一輪完整契約是為了同時處理 Q6(a) 的每輪一個測試，以及 Q6(c) 的所有指定決策須在實作前編碼。若授課者把每組 subTest 都視為一個獨立測試，這種分組可能不符合其對「一次一個失敗測試」的解讀；本報告不隱藏這個流程限制，也不把它說成多輪小步開發。
